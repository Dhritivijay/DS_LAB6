Project Overview
This lab is a two-part experiment blending statistical theory and applied data analysis using Python.

Part A (Probability): Simulation and visualization of core Probability Distributions (Uniform, Normal, Bernoulli, Binomial, Poisson) to understand their mathematical behavior.

Part B (EDA): Exploratory Data Analysis on the Titanic Dataset to uncover survival patterns based on key variables like Gender, Class, and Age.

 Tech Stack
Python

Libraries: NumPy, Pandas, Matplotlib, Seaborn

Key Findings
Probability
Successfully simulated and visualized the bell shape of the Normal Distribution and the discrete nature of the Poisson Distribution (rare events).

Titanic EDA
Gender and Class: Female and First-Class passengers had significantly higher survival rates.

Data Quality: Confirmed missing data in critical fields like Age and Deck via heatmap visualization.

 Usage
Clone this repository.

Install dependencies: pip install numpy pandas matplotlib seaborn.

Open and run the notebook (Lab-5.ipynb).

Outcome: Practical exposure to both mathematical simulations and real-world data insight generation (EDA).
